# Documentation impact

Apply after adding or changing persistent information.

- [ ] Searched existing documents, headings, synonyms, and contrary terms before choosing the destination.
- [ ] Identified the authoritative home or explicitly recorded that authority is unresolved.
- [ ] Updated the authoritative source instead of copying volatile details.
- [ ] Labeled assumptions, recommendations, hypotheses, decisions, and unknowns where needed.
- [ ] Checked new claims against related facts, policies, procedures, plans, and decisions.
- [ ] Surfaced unresolved contradictions rather than silently selecting a convenient source.
- [ ] Repaired links, indexes, aliases, and navigation affected by the change.
- [ ] Checked secondary summaries for staleness; replaced repetition with links where practical.
- [ ] Preserved decision and historical context through status or supersession when needed.
- [ ] Added lifecycle metadata only where it will help future verification or ownership.
- [ ] Ensured a new document is discoverable and has a distinct purpose.
- [ ] Proposed destructive reorganization separately unless implementation was explicitly authorized.
